新增「能力探测」：逐模型试出图片输入与工具调用能力。

### 新增功能

- 新增「能力探测」入口，用真实最小请求逐模型探测两项能力：图片输入（1×1 PNG 多模态请求，data URI 被网关拒收时自动回退仓库内资产链接重试）与工具调用（强制 `tool_choice` 的最小请求，以响应里的 `tool_calls` / `finish_reason` 判定，不拿 2xx 单独作数）。结论三态：支持 / 不支持 / 未得出结论（附原始状态与错误体摘要）。
- 图片输入结论可写回模型配置的图片模态字段（「自动写入」开关控制）；工具调用没有官方字段，只展示不写回。

### 体验优化

- 能力探测与「验证模型」「探测档位」同风格：同一模型卡片与弹层外壳、同样的超时 / 并发 / 取消处理、逐条记录进记录区，中英词条齐全。
- 探测均为计费可控的最小请求（单条消息、max_tokens=1、1×1 图片），弹层明示真实计费请求提示，全程可取消。

### 其他变更

- 新增仓库资产 `assets/probe-1x1.png`（1×1 PNG，与内嵌 data URI 常量同字节），图片探测回退链不依赖第三方图床。
- 设计裁决记录于 `docs/decisions.md`「能力探测」；`docs/host-api.md` 登记新增的宿主读取假设（`llm-pi-ai` 段的 `baseURL` / `apiKey` / `apiKeyEnv` 与凭据 `resolve` 取值）。
